Stand inside the venue with this page open on your phone or laptop, click Use my current location to capture accurate GPS automatically, then Save venue. It's remembered on this device/browser and will appear in the Venue dropdown above from then on — reuse it every week, no re-typing. Using the same name as an existing venue updates its saved coordinates.

Note for Haem Lab / Chem Path Lab / Micro Lab / Histo​/Cyto Lab: since these sit right next to each other on the same floor, ordinary phone GPS (accurate to roughly 5–30m, worse indoors) usually can't tell adjacent rooms apart. Capturing each one separately is still worth doing — it confirms students are on that floor/in that cluster of rooms — but don't expect it to catch someone sitting in the lab next door instead of the correct one.
